# Tabbed toolbar reference

These Apache-2.0 AOSP sources, tests, and artwork accompany the GPUI toolbar
adaptation selectively ported from Koda PR #58, commit
`ac58815bb268d338bea40a31fff630734cd719f4`.

The production adaptation is `../../src/tabbed_toolbar.rs`; its Rust tests run
against GPUI. The retained Java/Kotlin tests are reference material, not executable
Koda tests. The port does not include PR #58's Android project-model or tree work.

The icon attribution and license are also retained in
`assets/android-studio-attribution.md` for distributed assets.
